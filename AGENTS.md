# Правила работы

— Перед изменениями прочитай `PRODUCT.md`, `FLOW.md` и `TASKS.md`.
— Одна пользовательская задача за раз.
— Сначала план и способ проверки — без правок до согласования.
— Не меняй архитектуру, стек и библиотеки без отдельного объяснения.
— После правок запусти `npm run check`.
— Покажи изменённые файлы, результат проверки и ручной чек-лист.
— Не помещай секреты и данные покупателей в код — сайт их не хранит, всё через Tribute.
— При противоречии в задаче остановись и назови конфликт.
— После изменений обновляй `AGENTS.md`/`CLAUDE.md` и другие файлы, которые ИИ читает при каждом запросе.
