# DECISIONS.md

## 2026-07-14 — Локальный режим по умолчанию

**Почему:** участник получает первый результат без базы, аккаунтов и ключей.

**Что меняет:** база подключается только после рабочего прототипа и проверки, что данные действительно нужны.

## 2026-07-14 — Архив вместо безвозвратного удаления

**Почему:** новичок может нажать не туда. Архив безопаснее.

## 2026-07-14 — Один акцентный цвет

**Почему:** так проще сохранить визуальную иерархию во время правок агентом.

## 2026-09-16 — Дизайн блоков 1–2 переработан по скиллу `frontend-design`

**Почему:** установлен проектный скилл `.claude/skills/frontend-design` (учебный, тестировали на ветке `test/frontend-design-skill`) — он советует не использовать шаблонные «ИИ-дефолты» (тёмный фон + один яркий акцент — один из них), а строить визуальный язык из сути продукта. Продукт — про Google-таблицы, поэтому взяли эстетику самого инструмента: «шапка окна», адреса ячеек, вкладки листов.

**Что меняет:** появился набор переиспользуемых приёмов — см. `DESIGN_SYSTEM.md` → «Фирменные элементы». При дизайне блоков 3–5 сверяться с этим списком, чтобы не изобретать конфликтующий стиль и не тиражировать сигнатурные элементы (шапку-окно, ползунок) там, где им не место.
